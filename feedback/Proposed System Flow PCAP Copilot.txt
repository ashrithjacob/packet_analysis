Proposed Enhanced Flow

1. File Upload:
-User uploads PCAP(s) via Streamlit.
-The system confirms file receipt.

2. Query Definition:
-The system asks the user what they want to analyze.
-Based on the query, the LLM generates Tshark commands dynamically.

3. Initial Analysis:
-Tshark processes the PCAP(s) according to the generated commands.
-Extracted data is converted into a CSV (or Pandas DataFrame) for analysis.

4. Analysis and Presentation:
-The system uses the LLM to perform protocol-specific or general analysis on the extracted data.
-Results are presented in Markdown format using tables, bullet points, or flowcharts.

5. Follow-Up Handling:
-If the user has follow-up questions:
	-If related to existing data: LLM uses already extracted CSV/structured data for further analysis.
	-If new data is required: LLM generates new Tshark commands to extract additional fields.
-Repeat analysis and present findings dynamically.

6. Iterative Refinement:
-The system continues to refine Tshark commands, data extraction, and analysis based on user inputs.
